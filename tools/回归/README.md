# tools/回归 · 站点回归自检

一条命令确认「改完代码没碰坏东西」。

```bash
python "tools/回归/run.py"                # 全跑：路线 → 状态 → 链路
python "tools/回归/run.py" 路线            # 只跑一套
python "tools/回归/run.py" 状态 1 6        # 只跑状态套的第 1–6 档
python "tools/回归/run.py" 状态 7 11
```

## 三套各查什么

| 套 | 脚本 | 档数 | 查什么 |
|---|---|---|---|
| 路线 | `route-check.py` | 9 | 地址写什么 → 页面铺什么：四部直达条数、跨部检索、零结果空态、收藏直达、详情深链、id 打错回退 |
| 状态 | `state-check.py` | 11 | 加载中 / 成功 / 空 / 错误 四态 × 三个消费方（部浏览 `#/部/x` · 检索 `#/搜/词` · 收藏 `#/藏`） |
| 链路 | `flow-check.py` | 1 | 收藏与详情面板的完整交互链：取消收藏后列表跟不跟、关浮层地址收不收回、详情深链 |

## 目录

```
tools/回归/
├── run.py            总入口（三套串起来跑，最后给一句总结）
├── route-check.py    ├ 路线
├── state-check.py    ├ 状态
├── flow-check.py     ├ 链路
├── _壳.py            公共壳：路径推算 / 本地服务 / 无头 Edge 取样 / 探针装撤
├── 探针/             state.html · flow.html —— 跑之前拷进 yizhi/，跑完删
└── _dump/            只在失败时写：留一份 DOM 现场供翻案（已 gitignore）
```

## 依赖

- **本机 Edge**（`msedge.exe`）。不需要 Playwright / agent-browser / npm。
- **本机 Python 3**（`py` 或 `python` 都行），只用标准库，不装任何第三方包。
- **不用手起服务**：脚本自己起、自己关 —— 一条命令跑完就结束，不留常驻进程。

## ⚠️ 两个必须知道的坑

**1. 探针页跟脚本放一起（这条是血换的）**

探针页原来手写在 `yizhi/` 里、用完就删。下一次跑回归时它已经不在了 ——
于是**十一档全红、整轮只跑 12 秒**，症状极像产品代码被改坏，实际只是取样器没了。
现在探针页躺在 `tools/回归/探针/`，脚本开跑前拷进站点、结束时删掉（try/finally）。

**别把它挪出这个目录，也别让它在 `yizhi/` 里过夜** —— 站点目录会被整个发布。

**2. 取样时机：验异步渲染必须走探针**

`--dump-dom` 的取样点在页面 `load` 那一刻，而站点数据是异步 `fetch` 的。
直接 dump 会**同一档两轮红绿交替**，很容易被当成产品 bug 去改好代码。所以：

- 要验中间态（加载中 / 错误 / 空）→ 探针页 + 页尾 `<img src="/__never">` 把 load 钉住 + Edge `--timeout` 在**真实时间**取样；
- 只有「纯静态、不验中间态」的路线档 → 才可以用 `--virtual-time-budget` 快进。

另外：探针里的等待**不能用 `Date.now()` 计时**（虚拟时间会快进计时器 → 假超时），
一律按「迭代次数让出」。

## 跑不动时

| 症状 | 原因 | 怎么办 |
|---|---|---|
| `找不到 msedge.exe` | Edge 装在别处 | 改 `_壳.py` 里的 `edge候选` |
| `探针页不见了` | 探针被挪走或删了 | 从 git 恢复 `tools/回归/探针/` |
| 整轮几秒跑完且全红 | 探针没拷进站点（服务 404） | 看 `yizhi/` 下有没有 `_probe-回归-*.html` 残留；确认 `探针/` 里有文件 |
| 某档偶发红 | 取样时机 | 先重跑一次；连红两次再当 bug 查，先翻 `_dump/` 里的现场 |
| 命令超时被中断 | 一次起了太多无头实例 | 分批跑：`run.py 状态 1 6` / `run.py 状态 7 11` |

## 加一档

在对应脚本的 `档单` / `检查` 列表里追加一行即可：

- 路线档：`(路径, 名称, [(类型, 参数, 期望), ...])`，类型有 `计数 / 总条数 / 包含 / 不含`
- 状态档：`(说明, dict(路由=…, 态=…, 预置=…), [(含/不含, 片段), ...])`
- 链路档：探针 `探针/flow.html` 里多写一步 `记.push('字段=值')`，脚本里加一条断言
