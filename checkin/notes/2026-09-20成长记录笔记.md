Day 5，今天整件事是给"异兽志"定技术方案，产出 TECH_DESIGN.md 和一张数据流图，没写一行业务代码。

先把方案 A（纯静态，原生 JS + JSON + localStorage + GitHub Pages）和方案 B（加后端，云数据库 + 账号）按学习成本、线上持久化、费用、排错难度四项比了一遍，选了 A。最硬的理由是 PRD 第 8.6 节验收写着"本地双击能打开、不联网不登录"，B 第一个就不满足。代价也写进文档：收藏不跨设备、内容改不了，并给了三条"什么时候该回头加后端"的触发条件，另留了一份《后端预备方案》，你说要就用，不要整份删掉。

今天最该记的是图片版权那次掉头。我原本想"右下角标注来源，说明不是抄的"，小象直接否了：署名不但不免责，反而证明明知故用。我又说"仅供我个人使用"，它追问出三道闸门——图不进仓库、不做公网部署、链接不外发，破一条就从个人欣赏变成信息网络传播。最后我定：站要发链接，《观山海》只当画风基准，素材走 AI 生成做主、公版古籍刻本图做点缀，PRD 里那两条口径也改细了。

拉胯的有三处：版权的口径来回改了好几轮，根子是我先下结论再找依据；文档提交完才发现 ima 里存的还是旧版，来回补了两轮；推送时链路一直报错，连试六次都没通，最后自己开终端重跑一遍才上去。明天最要紧的就是把欠的截图一起补掉。
