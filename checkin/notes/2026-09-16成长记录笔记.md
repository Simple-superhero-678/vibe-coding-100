2026-09-16成长记录笔记

今天正式开始 vibe coding 打卡学习，第一天没干别的，就是把工具链配齐。

本机原来只有 WorkBuddy 里带的便携版工具，系统里既没有 Git 也没有 Node，都得自己装。Git 用官方安装包装的，还算顺。Node 就折腾了——先试 MSI 静默安装，一直失败，翻日志才看明白是 Windows Installer 跨沙箱读不到文件，报错码 2203，换成 zip 免安装版一次就过。这一下让我记住一个结论：本机装软件优先找 zip / 绿色版，别在 MSI 上耗时间。

四件套验收也都对上了：WorkBuddy、Git 2.55.0、Node v22.22.2 配 npm 10.9.7、GitHub 账号登录状态。概念这块今天过了两个词，vibe coding 和 skill——前者是把自己当提需求的人、AI 当干活的人，但出来的东西必须自己验收；后者是给 AI 反复用的一份标准说明书。用自己的话复述了一遍，尤其记住了"AI 生成的代码要自己查 bug"这一环。

今天有做得不好的地方：交截图时两张文件管理器的图不合格，一张只截了路径、一张只有一个文件，最后我选择跳过补拍，没有当场补好，这点是偷懒了。

整体感受是配环境这事看着琐碎，但踩过的每个坑都是真经验。明天开始真正动手。
