Day 7 是这周最重的一天，十步清单要把一个能跑的 MVP 从零立起来。开工前先把四份底料读完，挑出六处文档与代码对不上的地方报给宝哥，他逐条拍完我才动手。

主体分步搭：先让页面能跑，再依次建数据层 data.js、视图层 views/grid.js、检索层 search.js，最后接吉凶筛选。检索走 2-gram 倒排，输"妲己"能落到九尾狐，这是全站的差异化核心。中途宝哥两次说视觉单调，补了版框、书耳一类古籍元素后，干脆按他的意思整体改成卷轴概念——上下轴、两侧云纹、垂挂书签、水墨渐变底、三枚漂浮印，全用 CSS 和 SVG 现画，一张图没引。写 README 时顺手实测出 file:// 双击只剩空骨架：不是文档预判的"读不到 JSON"，是模块脚本和 fetch 双双被拦、JS 一行没跑，与 PRD 8.6 直接冲突，宝哥定"搁置到 M7 前"。第 8 步自查 45 项断言全过，第 9 步两个提交推送，第 10 步出结构图，收口 23cdfb6。收尾把 12 条名单从 v1 升到 v2，读齐六篇摘要、逐条核过 12 条《山海经》原文与历代注疏。

拉胯三处。视觉来回三轮，第一版页边纹带做太浓，像一道栅栏把留白气质压掉，只能推翻重做；无头浏览器加 --window-size=390 时的视口并不是 390 个 CSS 像素，截图里"标题消失、卡片被裁"演得活灵活现，差点让我去改一段本来没问题的代码；核对推送那条命令因为本机缺 cut 而静默短路，输出一片空白，看着和"通过"一模一样。最实在的是：这一天大部分时间全站只有 1 条数据，"页面空旷、搜一条只一条、筛选三个按钮是 0"全是这一个病根。

傍晚宝哥把四处细节全定了，还加了句硬规矩——以后待决的事我一律按"选项＋各自代价＋我的建议"摆出来，他只负责判断。12 条当场灌进 data/yishou.json，站况从"1 条"翻成"12 条"，四个筛选按钮全有数，那条"只有一条数据"的老病根当场解掉。剩下的是 11 张配图，那属 M2。

晚饭后没停，一鼓作气把剩下的全清了。先补异兽部 11 张配图，12 条全带图，M2 收口；再做详情面板、云中仙槎转场、收藏与导出，M4 收口。接着境界部、神仙部、神话部、妖怪部四部连着补，全站到 96 条，五部各有自己的形态——谱系树、时间轴、图鉴网格、六类分组、竖轴，境界部还做了双序列对照：网文九阶用阿拉伯数字线框阶章，真丹道的五等用朱砂实印。检索改成一次搜五部、结果卡带部角标，收藏也能跨部，刷新后还在。最后是上线：写发布流水线，只发运行时要的东西，站点根设在 yizhi/。

拉胯的地方全在最后这一段。流水线头一次跑就红，而且红在我自己写的那道发布自检上：脚本里用了中文变量名，bash 不认那是赋值、把它当成命令名去找，整步以 127 退出、什么输出都不给；定位时我第一反应还猜错了方向，怀疑是 find 命中了起始目录，本地真跑一遍这个假设就崩了。改成 ASCII 变量名后一次就绿。另一半时间卡在 GitHub Pages 一直没启用——那是网页设置项，脚本改不动，最后借 git 里存的凭据调官方接口才开起来。现在线上地址能打开，底稿、台账、私有图和出图样张全部 404，没漏一件过程文件上公网。
