# 异兽志 · 云中仙槎转场

> `yizhi/` ｜ 2026-09-19
> 库内原稿：`驴肉的知识库/1-Projects 项目/异兽志/01-异兽志·云中仙槎转场方案.md`（快照）

**一句话**：检索到条目后，画面从舟内平移到舟外，仙槎飞掠传统世界，停在那一条上。

---

## 一、要做成的效果

- 一个镜头：从"隔着船窗往外看" → "飞在云海之上"
- 全程墨色剪影 + 一点朱砂（舟）。像一张宣纸自己在动
- 落点就是条目本身——动画不额外占时间，直接接详情面板

---

## 二、分镜（约 3 秒）

| 段 | 时间 | 画面 | 动的是什么 |
|---|---|---|---|
| ① 舟内 | 0–0.8s | 宣纸底。前景两根船帮（浓墨剪影），中间一块留白当窗，窗外云气缓移 | 云气极慢横移 |
| ② 出舟 | 0.8–1.6s | 船帮向外滑出画面，窗框散开，视野整个打开 | 前景出画 |
| ③ 飞掠 | 1.6–2.8s | 四层剪影横移，由慢到快。朱砂的舟钉在画面中下部不动 | 层层错位移动 |
| ④ 停靠 | 2.8–3.3s | 各层减速归零，朱砂点升起成印章 | 减速 + 印章放大 |
| ⑤ 到站 | 3.3s+ | 印章放大 → 详情面板展开 → 文字淡入 | 交给 M4 |

**速度就是动感**：位移造速度，不加光效。

| 层 | 元素 | 横移周期 | 色 |
|---|---|---|---|
| 1 | 远山 | 12s | `--ink-2` |
| 2 | 中景山 + 云 | 8s | `--ink-2` |
| 3 | 近景树石 / 浪 | 4s | `--ink` |
| 4 | 舟（不动，只微起伏） | 0 | `--cinnabar` |
| 5 | 船帮 / 窗框（② 段出画） | 出场 | `--ink` |

---

## 三、怎么做

不引库，一个 section 几层 div。

```html
<section class="voyage">
  <div class="layer l1"></div><div class="layer l2"></div>
  <div class="layer l3"></div><div class="layer l4"></div>
  <div class="cabin"></div>   <!-- ② 段出画的窗框 -->
</section>
```

```css
.layer{ will-change:transform; animation:drift linear infinite; }
.l1{ animation-duration:12s }  .l3{ animation-duration:4s }
.cabin{ transition: transform .8s var(--ease), opacity .8s var(--ease); }
.voyage.is-open .cabin{ transform: translateY(60%) scale(1.6); opacity:0; }
```

- ①→② 只要给 `.voyage` 加 `is-open` 类，不用 3D
- 只用 `transform`，不用 `left/top`
- ④ 的减速用 CSS 不好使，这步上 `requestAnimationFrame` 控偏移（约 20 行）

```css
@media (prefers-reduced-motion: reduce){ .voyage{ display:none } }
```

**播放**：首播完整 3s，之后 600ms 短版；点击或滚动立即到站。

## 四、分三步做

| 步 | 做什么 | 挂在哪 |
|---|---|---|
| **0** | **先出一帧静帧**：墨山剪影 + 留白云 + 朱砂的舟 | 搭 M2 视觉的顺风车 |
| 1 | 拆层横移，速度不同 = 在动 | M3 之后 |
| 2 | 窗框放大 + 到站，接详情面板 | M4 |
| 3 | 真 3D 云海 | M7 之后，独立分支 |

**第 0 步是闸门**：静帧不够看，后面全不做。
