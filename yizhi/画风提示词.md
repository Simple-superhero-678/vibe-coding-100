## 三、变量模板

```
[FIXED POSITIVE] Subject: {ZH_NAME} ({PINYIN}, {EN_GLOSS}) — alias: {ALIASES}. Source: {SOURCE}. Form: {BODY_DESCRIPTION}. Expression and pose: {EXPRESSION_POSE}. Cinnabar accent: {CINNABAR}. Negative: [FIXED NEGATIVE]
```

| 变量 | 填什么 | 约束 |
|---|---|---|
| `{ZH_NAME}` | 条目名（中文） | 必须与 `data/*.json` 的 `名` 字段一致 |
| `{PINYIN}` | 拼音 | 绘图模型不认识汉字，靠拼音兜底 |
| `{EN_GLOSS}` | 一句话英文形态 | 5 词内，例 `nine-tailed fox` |
| `{ALIASES}` | 别名 | 只作 lore 参考，**不许画成人形**（如「妲己」） |
| `{SOURCE}` | 出处 | **单值**，格式「书名·卷篇」；异说来源另列，不混写 |
| `{BODY_DESCRIPTION}` | 原文形体 | 从 `原文` 字段压缩，不自己编 |
| `{EXPRESSION_POSE}` | 神态与姿态 | 落到具体动作，不写「威武」这类空词 |
| `{CINNABAR}` | 朱砂用在哪 | **写死具体位置**，例 `the eye only, one dot`；不许写笼统的 `red accents`（否则会跑到鼻头、嘴上） |

## 四、示例：九尾狐（`yishou-001` 候选）

```
[FIXED POSITIVE] Subject: 九尾狐 (jiu wei hu, nine-tailed fox) — alias: 妲己 (novel epithet only, not a human form). Source: Shan Hai Jing · Nan Shan Jing. Form: a fox with nine tails, its cry like a baby's. Expression and pose: sitting upright and poised, calm clear eyes looking forward, elegant and dignified. Tails: a free-flowing mass of many tails spreading behind the body like layered ink washes — impressionistic, the count need not be literal. Cinnabar accent: the eye only, one dot. Negative: [FIXED NEGATIVE]
```

> 注意一：原文里的「能食人」**不进画面提示词**。它是事实，留在网站的「原文 / 兆 / 写小说怎么用」字段里；写进提示词只会把模型推向獠牙、血迹、凶相。
>
> 注意二：`nine tails` 只作**形态描述**，不要求画满九条。见口径「尾部」——硬数字已被两次实测证明无效。

## 五、四条纪律

1. 两块 FIXED **只存一份**（就是本文件），逐条拼装。不要在每条里重复整段——12 条重复 12 遍，改一处必漏。
2. **先出样图**给宝哥过目。画风不对，12 张全废。
3. 出图规格：竖构 3:4；四周 ≥8% 安全边（防裁切切到爪、尾）。落地统一转 webp、尺寸 900×1200、文件名 = 条目 id（`yishou-001.webp`）。
4. 每张图必须记进 `assets/SOURCES.md` 台账：工具 + 日期 + 完整提示词 + 是否验收。来源不明不收。

## 六、六条已定口径（09-21）

| 项 | 决定 |
|---|---|
| **气质红线** | **柔和，不黑暗。** 参照《观山海》是取它的瑰丽与庄重，不是取它的阴森。**笔法可以利，气质不能凶**——线条保持凌厉，神态必须柔、暖、静 |
| **墨感口径** | **墨感 ≠ 纯黑。** 墨感指毛笔蘸水后在纸上呈现**浓淡分明的层次**（墨分五色：焦、浓、重、淡、清），是"颜料在纸上的厚薄深浅"，不是把颜色涂到最黑。所以提示词要**要层次**，同时**禁平涂死黑**——两者不矛盾 |
| **尾部口径** | 「九」**不硬数**。改为写意：尾巴多而飘逸、层叠如墨，不要求逐条可数。写实数尾已两次实测失败（v1 出 2–3 条、v2 出 6–7 条且糊成烟），不再投入 |
| 图上要不要远山 / 云气 | **禁**。留白是这站的气质本体 |
| 公版古籍刻本图怎么放 | **只作详情页点缀**，不与主图同网格混排（线刻黑白 × 水墨重彩会脏） |
| **样图入库时机** | **样图最终形式定下来之后才入库。** `yizhi/预览/样图/` 目前只是草稿目录，**不进 Git** |

**两条教训（都是被样图打出来的）**：

1. **「凶」的词别进画面提示词。** 首图偏暗，一半原因是我们自己写了 `imposing mythic presence`、`man-eating`、`sharp claws`。删词比事后调图省事。
2. **「柔和」不等于「淡」。** 第二张为了柔，把墨压得太淡，跌成淡彩，水墨的厚度没了。正确的做法是**柔在气质、厚在墨的层次**——不是把墨调浅。
