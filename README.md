## 一、本地怎么跑起来

**必须起一个本地 http 服务，不能双击 `yizhi/index.html`。**

```bash
cd yizhi                      # 关键：服务根目录是 yizhi/，不是仓库根
python -m http.server 8000 --bind 127.0.0.1
```

然后浏览器打开 → **http://127.0.0.1:8000**

- 停服务：回终端按 `Ctrl+C`
- 端口被占：换 `8001`、`8002`……
- `python` 命令不存在：试 `py -m http.server 8000`

### 为什么不能双击打开（Day 7 实测）

| 打开方式 | 结果 |
|---|---|
| 双击 `yizhi/index.html`（`file://`） | ❌ 页面只剩空骨架——五部 tab、筛选条、卡片**全不出现** |
| 同上，但浏览器加 `--allow-file-access-from-files` | ✅ 完全正常（`站况 = 异兽部 · 1 条`，卡片出图） |
| `http://127.0.0.1:8000/` | ✅ 完全正常 |

原因：页面是 `type="module"` 的 ES 模块，数据用 `fetch` 读 `data/*.json`。`file://` 下浏览器默认**把这两样都拦掉**（origin 是 `null`），所以 JS 一行都没跑。加那个浏览器参数就正常 —— 证明是浏览器的安全策略，不是代码写错。

⚠️ 这与 `PRD.md` §8.6「本地双击能打开」不一致，已记为待决项（见 `TECH_DESIGN.md` §14-4）。**动手改架构之前先问宝哥。**

### 两套图源

| 在哪打开 | 用哪个图片目录 | 说明 |
|---|---|---|
| `http://127.0.0.1/…`（本地） | `assets-private/` | 《观山海》原图，只在本机，`.gitignore` 挡住，**永不入库、永不上公网** |
| `https://`（将来线上） | `assets/` | AI 生成图 / 公版古籍图，进 git、可公开 |

私有图没放时**逐图**自动回退公开图，所以本地不会出现破图。
强制看另一套：地址后加 `?图源=public` 或 `?图源=private`。

    ├── js/
    │   ├── main.js           ← 入口：启动、装配、事件绑定
    │   ├── data.js           ← 数据层：读 JSON + 校验
    │   ├── search.js         ← 检索层：建索引 + 排序
    │   └── views/grid.js     ← 视图层：图鉴网格 + 筛选谓词

目录纪律：**代码只改 `yizhi/`**；数据只改 `data/*.json`（页面是渲染结果，在页面上改不落地）。

## 四、怎么加一条数据

1. **先加图**：按条目 id 命名，转成 `.webp`，放 `yizhi/assets/`，同时登记 `assets/SOURCES.md`（来源不明的图不收）。
2. **再加数据**：往 `yizhi/data/yishou.json` 的 `条目` 数组里追加一条。

```json
{
  "schema": 1,
  "部": "异兽",
  "更新": "2026-09-22",
  "条目": [
    {
      "id": "yishou-001",
      "部": "异兽",
      "名": "九尾狐",
      "吉凶": "吉祥",
      "图": "yishou-001",
      "别名": ["九尾", "青丘之狐", "妲己"],
      "原文": "青丘之山，有兽焉，其状如狐而九尾……",
      "出处": "《山海经》·南山经",
      "写小说怎么用": "吉兆场面的现成素材……"
    }
  ]
}
```

必填：`id` / `部` / `名` / `原文` / `出处` / `写小说怎么用` / `别名`（可为空数组），A–D 部还要 `吉凶`。
`图` 的值**就是条目 `id`**（`yishou-001` ↔ `assets/yishou-001.webp`），不放扩展名。
`吉凶` 只有四个值：吉祥、凶恶、灾祸、无害；不在枚举内的一律当「未分类」（只在无筛选时出现）。

改完刷新页面即可，**没有构建步骤**。

> 唯一的判定口径：每条内容都要能回答「**写小说时我怎么用**」。写不出来，就不该进站。
