## 四、怎么导出数据（两条路径）

### 路径 A：整表快照（MCP 只读 SQL · 本次实操）

```sql
-- favorites 全表（直接得到 JSON 文本）
SELECT json_agg(t)::text FROM (SELECT * FROM public.favorites ORDER BY created_at, id) t;
-- users 全表
SELECT json_agg(t)::text FROM (SELECT * FROM public.users ORDER BY id) t;
```

把返回的 `snap` 文本存成 `.json` 即完成导出。优点：零依赖、一条 SQL；
注意：单次返回有体积上限，大表要分批（本表 23 行无压力）。

### 路径 B：控制台导出（数据多了以后用）

控制台 → 「数据库」→ 选中实例/`public` 库 → 「导出」（生成文件下载）。
> 若免费版导出入口不可用，退回路径 A（逐表 SQL）+ 本地留档。

### 恢复（把快照倒回去）

属于**写操作**：先备份当前表，再用 `managePgDatabase(confirm=true)` 执行 INSERT；
执行前必须再次人工确认（入口与写动作同样遵守「凭据不进仓库」的纪律）。
